# Gig வேலைகள்

Gig வேலைகள் என்பது நீண்ட தொழில்களுக்கிடையில் நீங்கள் செய்யக்கூடிய குறுகிய குடிமக்கள் பணிகள். அவை முழு ஷிஃப்ட்களை விட விரைவான காட்சி படிகளைச் சுற்றி அமைந்தவை: prompt-ஐ படிக்கவும், சிறிய interaction-ஐ முடிக்கவும், waypoint-ஐ பின்தொடரவும், பின்னர் பணத்தைப் பெறவும்.

உங்களுக்கு பல்வகைத் தன்மை, விரைவான Ringgit வரவு, அல்லது நகரம் முழுவதும் உங்களை அழைத்துச் செல்லும் வேலை வேண்டும்போது இவை நல்லவை.

## Gig வகைகள்

| Gig | நீங்கள் செய்வது | அடிப்படை வெகுமதி |
| ----- | ------------- | ------------- |
| E-Hailing | பயணியை ஏற்றி இறக்குதல் | 40 SR, 8 XP, 30% tip வாய்ப்பு |
| Pos Nasional | பார்சல்கள் வழங்குதல் | ஒவ்வொரு பார்சலுக்கும் 35 SR மற்றும் 7 XP, 10% tip வாய்ப்பு |
| Tow Truck | வாகனத்தை மீட்க அல்லது நகர்த்த | 80 SR, 12 XP, 20% tip வாய்ப்பு |
| Reporter | இடத்தை அடைந்து கதை தருணத்தை பதிவு செய்க | 50 SR, 10 XP, 15% tip வாய்ப்பு |
| Tour Guide | points of interest வழியாக ஒரு பாதையை வழிநடத்துதல் | 120 SR, 20 XP, 40% tip வாய்ப்பு |
| Restaurant Supplier | உணவகத்திற்கு பொருட்கள் வழங்குதல் | 45 SR, 8 XP, 10% tip வாய்ப்பு |

Tips உறுதி செய்யப்படவில்லை, எனவே சுத்தமான runs-க்கு அவற்றை bonus ஆக கருதுங்கள்.

## அவை எப்படி விளையாடப்படுகின்றன

ஒரு gig தொடங்கும்போது, உங்கள் HUD தற்போதைய நோக்கத்தை காட்டும். சில gigs அடுத்த படிக்காக சிறிய minigame panel-ஐ திறக்கும்:

- **Manifest / paperwork** - மென்மையான காகித ஒலியுடன் காகித பாணி panel தோன்றி, பிறகு உங்களுக்கு வேண்டிய item அல்லது route-ஐ காட்டும்.
- **Choice steps** - சில buttons-இல் இருந்து சரியான செயலைத் தேர்ந்தெடுக்கவும்.
- **Sequence steps** - காட்டப்பட்ட வரிசையை மீண்டும் செய்யவும்.
- **Timing steps** - நகரும் marker-ஐ target zone-இல் நிறுத்தவும்.

Panels தொலைபேசி, tablet, மற்றும் desktop திரைகளில் வேலை செய்கின்றன. Mobile-இல், buttons மற்றும் text பெரியதாக மாறும், அதனால் நம்பகமாக தட்ட முடியும்.

## Camera focus

சில படிகள் நீங்கள் கவனிக்க வேண்டிய item, பயணி, route marker, அல்லது scene நோக்கி camera-வை குறுகிய நேரம் நகர்த்தும். இது தானாக நடக்கும் மற்றும் படி முடிந்ததும் கட்டுப்பாடு திரும்பும், எனவே settings மாற்ற வேண்டியதில்லை.

Main Menu அல்லது Cinematic app போன்ற இன்னொரு வலுவான camera mode செயலில் இருந்தால், gig இன்னும் வேலை செய்யும்; அது focus move-ஐ மட்டும் தவிர்க்கலாம்.

## நிறுத்துதல் மற்றும் reset

Run இடைநிறுத்தப்பட்டால் gig jobs தானாக சுத்தம் செய்கின்றன. நீங்கள் இறந்தால், server-ஐ விட்டு சென்றால், அணியை மாற்றினால், இணங்காத வேறு வேலையைத் தொடங்கினால், அல்லது நோக்கம் மறைந்தால், செயலில் உள்ள panel மற்றும் camera focus நீக்கப்படும்.

ஒரே நேரத்தில் ஒரு வேலை மீது மட்டும் கவனம் செலுத்த முடியும். இடைநிறுத்தத்திற்குப் பிறகு gig தொடரவில்லை போலத் தெரிந்தால், gig/career prompt அல்லது interface-இல் இருந்து புதிதாக தொடங்குங்கள்.

## குறிப்புகள்

- முதலில் task card மற்றும் minimap-ஐ பாருங்கள்; minigame panel பொதுவாக அதே நோக்கத்தை உறுதிப்படுத்தும்.
- Timing steps-க்கு, marker highlighted zone-இன் நடுவில் அமர்வதை காத்திருந்து தட்டுங்கள்; மிக முன்பே தட்ட வேண்டாம்.
- Pos Nasional ஒவ்வொரு parcel-க்கும் பணம் தருகிறது, எனவே பல parcel runs தோன்றுவதைக் காட்டிலும் நல்லதாக இருக்கலாம்.
- Tour Guide சிறந்த base payout கொண்டது, ஆனால் பல இடங்களுக்கு அழைத்துச் செல்லும் என்பதால் அதிக நேரம் ஆகலாம்.
