# கட்டுப்பாடுகள்

Lebuhraya விசைப்பலகை, கேம்பேட், தொடுதிரை மற்றும் VR ஆதரிக்கிறது. விளையாட்டு உங்கள் தளத்தை தானாகவே கண்டறிந்து விளையாட்டில் சரியான வழிகாட்டிகளை காட்டும். ஒரு கட்டுப்பாடு திரையில் காட்டப்பட்டால், அதை பயன்படுத்துங்கள். கீழே உள்ள குறிப்பு பொதுவான பட்டன் பிணைப்புகளை விளக்குகிறது.

## வாகனங்களில் நுழைவதும் வெளியேறுவதும்

ஓட்டுனர் அல்லது பயணி இருக்கையிலிருந்து சுமார் **6 studs** தூரத்தில் நிற்கவும்.

| தளம் | பட்டன் |
|---|---|
| விசைப்பலகை | **F** |
| கேம்பேட் | **X** (கட்டுப்படுத்தியின் முகப் பட்டன்) |
| தொடுதிரை | திரையில் **Drive** / **Sit** பட்டனை தட்டவும் |
| VR | **வலது தூண்டுவி (R2)** |

அதே உள்ளீடு இருக்கையிலிருந்து வெளியேற பயன்படுகிறது.

### இருக்கை அனுமதிகள்

ஓட்டுனர் இருக்கைகள் பொதுவாக வாகனத்தின் உரிமையாளருக்கு பூட்டப்பட்டிருக்கும். நீங்கள் வேறொருவரின் காரில் அமர முயன்றால், அவர்கள் உங்களுக்கு திறக்காத வரை தடுக்கப்படுவீர்கள்.

## வாகனம் ஓட்டுதல்

பெரும்பாலான வாகனங்கள் இந்த இயல்புநிலை ஓட்டுதல் கட்டுப்பாடுகளை பயன்படுத்துகின்றன:

| செயல் | விசைப்பலகை | கேம்பேட் |
|---|---|---|
| முடுக்கவும் | **W** | வலது தூண்டுவி (RT) |
| பிரேக் / பின்னோக்கி | **S** | இடது தூண்டுவி (LT) |
| இடதுபுறம் திரும்பவும் | **A** | இடது ஸ்டிக் |
| வலதுபுறம் திரும்பவும் | **D** | இடது ஸ்டிக் |
| கை பிரேக் | **Space** | A / RB |
| திசைகாட்டிகள் / விளக்குகள் திரும்பவும் | **E**, **Q**, **I**, **J**, **H** (மாறுபடும்) | விளையாட்டில் வழிகாட்டிகளை பாருங்கள் |
| ஹார்ன் | **H** (பெரும்பாலான வாகனங்களில்) | வலது ஸ்டிக் கிளிக் |

::: info
விளையாட்டில் பழைய மற்றும் புதிய சேஸிஸ் அமைப்புகளுக்கிடையே வாகன விளக்கு கட்டுப்பாடுகள் மாறுபடுகின்றன. நீங்கள் ஓட்டும் குறிப்பிட்ட வாகனத்திற்கான திரை வழிகாட்டிகளை எப்போதும் பின்பற்றவும்.
:::

### அருகாமை வழிகாட்டிகள்

பெரும்பாலான உலக தொடர்புகள் Roblox ProximityPrompts பயன்படுத்துகின்றன: வாகன உருவாக்கிகள், கதவுகள், வேலை கவுண்டர்கள், எரிபொருள் பம்புகள், பழுதுபார்க்கும் மண்டலங்கள், இழுக்கும் பலகைகள் மற்றும் கடை கவுண்டர்கள்.

- வழிகாட்டி தோன்றுவதற்கு போதுமான அளவு நெருங்கி நிற்கவும்.
- நேர கட்டுப்பாடு இருந்தால், வட்டம் நிறைவடையும் வரை காட்டப்பட்ட கீ/பட்டனை அழுத்திப் பிடிக்கவும்.
- வழிகாட்டி தவறான அணியில் இருக்கிறீர்கள் அல்லது தவறான எரிபொருள் பம்பில் இருக்கிறீர்கள் என்று கூறினால், வழிகாட்டி சரியாக வேலை செய்கிறது; எச்சரிக்கையை பின்பற்றவும்.

### முக்கிய மெனு தாவல்கள்

முக்கிய மெனுவை திறந்து அணுகவும்:

- **முகப்பு** - அறிவிப்புகள் மற்றும் கண்ணோட்டம்
- **அணிகள்** - உங்கள் அணியை தேர்ந்தெடுக்கவும் / அணி மாற்றவும்
- **கடை** - விளையாட்டில் கொள்முதல் (gamepass வழிகாட்டிகள், tokens)
- **செயல்பாடு** - பணிகள், சவால்கள் மற்றும் Season Pass முன்னேற்றம்
- **மேலும்** - கார்டு கட்டம்:
 - **தொழில்** - உங்கள் தொழில் தரவரிசைகள் மற்றும் நிறுவன முன்னேற்றம்
 - **வேலைகள்** - கிளை வாரியான நிலை பட்டைகள் மற்றும் வெகுமானங்கள்
 - **Tokens** - உங்கள் செயலில் உள்ள மற்றும் சேமித்த tokens / அதிகரிப்புகள்
 - **வரவேற்பு** - மேம்பாட்டு குழு மற்றும் பங்களிப்பாளர்கள்
 - **பந்தயங்கள்** - நேர சோதனை மற்றும் PvP பந்தய மெனு
 - **உதவி** - கிடைத்தால் பயிற்சிகள்

தொழில், வேலைகள், Tokens, வரவேற்பு, பந்தயங்கள் மற்றும் உதவி **மேலும்** கீழ் தொகுக்கப்பட்டுள்ளன.

### நீங்கள் மாற்றக்கூடிய அமைப்புகள்

இந்த திருப்புகளுக்கு அமைப்புகள் பலகையை (முக்கிய மெனுவில் பற்சக்கரம்) திறக்கவும்:

- **விபத்து அமைப்பு** - கிடைக்கும்போது வாகன சேதத்தை இயக்கவும். செயலில் இருக்கும்போது **+15% XP** வழங்குகிறது, ஆனால் கடுமையான விபத்துகள் உங்களை காயப்படுத்தலாம்.
- **மேல் தரவரிசை** - உங்கள் கதாபாத்திரத்திற்கு மேலே மிதக்கும் அணி தரவரிசை/தலைப்பை காட்டவும் அல்லது மறைக்கவும்.
- **முதல் நபர் காட்சி** - கேமரா முறையை மாற்றவும். முன்னோக்கு சாய்கோடு (`/`) விளையாட்டில் காட்சியை திருப்பும்.
- **வாகன உருவாக்கி: புதியது** - புதுப்பிக்கப்பட்ட வாகன உருவாக்கி திரையை தேர்ந்தெடுக்கவும்.
- **கை பிரேக்** கீ - கை பிரேக் பிணைப்பை மீண்டும் மாப் செய்யவும்.
- **Shift + C** - முழு HUD-ஐ திருப்பவும் (ஸ்கிரீன்ஷாட்களுக்கு நல்லது).
- மீட்டமை / மாற்று / அகற்று - மறுவைப்பு மற்றும் தனிப்பயனாக்கல் குறுக்குவழிகள்.

### திரை மேல் குறிகாட்டிகள்

- **செயலில் உள்ள tokens** - இயங்கும் அதிகரிப்புகளை அவற்றின் மீதமுள்ள நேரத்துடன் காட்டுகிறது.
- **நிலை காட்சி** - வாகனம் ஓட்டும்போது வேகம், எரிபொருள், GPS திசை மற்றும் உடல்நலம் தகவலை காட்டுகிறது.
- **முன்னணிப் பலகை** - ஆன்லைன் வீரர்கள், அவர்களின் அணி, நிலை மற்றும் ஓட்டுதல் தூரம் காட்டுகிறது. Roblox சமூக விருப்பங்களுக்கு ஒரு வரிசையை தட்டலாம்.

## கருவிகள் (வேலை உபகரணங்கள்)

நீங்கள் ஒரு கருவியை வைத்திருக்கும்போது - கோடாரி, ரேடார் துப்பாக்கி, டேசர், பேஜர், தீ குழாய் - கட்டுப்பாடுகள் அந்த கருவிக்கு குறிப்பிட்டவை. திரை வழிகாட்டிகளை பயன்படுத்தவும் அல்லது அதை பயன்படுத்தும் அணியின் வேலை பக்கத்தை சரிபார்க்கவும்.

## கைபேசி குறிப்புகள்

- விளையாட்டு கைபேசி தளவமைப்பை மதிக்கிறது; தொலைபேசியில் வாகனம் ஓட்டுவது வேலை செய்கிறது ஆனால் டேப்லெட்டில் எளிதானது.
- பெரும்பாலான ProximityPrompts (கதவுகளில் நுழைவது, NPC-களிடம் பேசுவது, வேலைகளை தொடங்குவது) திரையில் வட்ட பட்டனை காட்டுகின்றன. அதை தட்டவும்.
- வாகனம் ஓட்டும்போது HUD-ன் இடதுபுறத்தில் ஸ்டீரிங் வீல் கிடைக்கிறது.
- Roblox-ன் இயக்க ஸ்டிக் மற்றும் தாவல் பட்டன் கீழ் மூலைகளில் இருப்பதால், வாகனம் அல்லாத UI-க்கு அந்த மூலைகளை அழுத்திப் பிடிப்பதை தவிர்க்கவும்.
- கார்டு கட்டம் அல்லது மெனு நெரிசலாக உணர்ந்தால், சாதனத்தை நிலைப்படுத்திய திரை (landscape) முறைக்கு சுழற்றவும். முக்கிய மெனுவின் மேலும் மற்றும் அணிகள் காட்சிகள் குறைந்த உயரமுள்ள நிலைப்படுத்திய திரைகளுக்கு பொருந்தும்படி வடிவமைக்கப்பட்டுள்ளன.

## கேம்பேட் குறிப்புகள்

- மெனு பட்டன்கள் தேர்ந்தெடுக்கக்கூடியவை. கவனம் இழந்ததாக தோன்றினால், மெனுவை மூடி மீண்டும் திறக்கவும், விளையாட்டு முதல் பட்டனை மீண்டும் தேர்ந்தெடுக்கும்.
- கார்டுகளுக்கிடையே நகர D-pad/இடது ஸ்டிக் பயன்படுத்தவும், உறுதிப்படுத்த **A**, UI திரும்பு அல்லது மூடு செயலை காட்டும்போது வெளியேற **B**.
- சில பழைய Roblox பலகைகள் இன்னும் கர்சர் பாணி தேர்வை நம்பியிருக்கின்றன; ஒன்று அசௌகரியமாக உணர்ந்தால், சிறிது நேரம் மவுஸ்/தொடுதிரைக்கு மாறவும்.

## அணுகல் திறன்

- Roblox-ன் முழு அமைப்பு அளவிலான அமைப்புகள் பொருந்துகின்றன - நிறக்குருட்டு வடிகட்டிகள், UI அளவிடல், உரை-க்கு-பேச்சு.
- கருவி மற்றும் ஆயுத தொடர்புகளை தடுக்க செயலற்ற முறையை திருப்பலாம். போர் அல்லது அவசரகால பங்கு நாடகத்தில் ஈடுபட விரும்பவில்லை என்றால் இது பயனுள்ளது.
