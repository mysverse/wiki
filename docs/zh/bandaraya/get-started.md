# 开始体验 Bandaraya

**Bandaraya** 是 Roblox 上的一款马来西亚城市角色扮演体验,以吉隆坡为背景。你选择一个角色,出生进入城市,与其他玩家一起演绎日常或紧急服务的故事。

游戏内货币是 **BR(Bandar Ringgit)**。本 wiki 中的价格均使用 BR,除非标注为 **R$** 表示 Robux。

## 你可以做什么

- **选择角色。** 当平民、警察、消防员、医护人员、军人、巴士司机、出租车司机、邮政员工、拖车操作员或其他专业角色。
- **赚钱工作。** 送信、开出租车、运营巴士、拖车,如果想更快开始也可以购买 BR。
- **驾驶。** 如果你的队伍有权限,可以使用民用汽车、摩托车、巴士、紧急车辆、军用车辆和直升机。
- **在吉隆坡四处旅行。** 乘巴士、用 MRT 或单轨快速旅行,或开车通过 TapNGo 收费站。
- **使用 CAG。** Click and Go 卡可用于巴士、MRT/单轨折扣、收费站折扣和月票。
- **响应紧急情况。** 警察、消防、医疗和军事队伍都有各自独特的角色。
- **角色扮演法律和后果。** POLIS 可以扣留、戴手铐、逮捕和开传票。嫌疑人会服一段短期监禁,然后回归游戏。
- **购物和定制。** 购买食物、衣服、工具、汽车和某些有牌照的物品。

## 背景设定

Bandaraya 涵盖了吉隆坡的游戏版本。你将看到来自真实吉隆坡灵感的地方,例如 PETRONAS 区、Ampang Park、Bukit Bintang、IPD Dang Wangi、主要酒店、银行大厦、巴士枢纽和 MRT/单轨车站。

许多队伍以马来西亚机构为蓝本,包括 **POLIS**、**BOMBA**、**KKM**、**SJAM**、**RELA**、**MAF** 和 **KPTD**。如果某个缩写不熟悉,请查看[词汇表](/zh/bandaraya/glossary)。

你在 Bandaraya 的前十分钟,从加入服务器到在吉隆坡四处走动。

## TL;DR

1. 选择 **Visitors** 或 **Malaysians**。
2. 出生并打开地图。
3. 如果需要 BR 就尝试一份工作。
4. 使用 MRT、巴士、出租车或车辆出行。
5. 加入执法、紧急或战斗角色扮演前阅读规则。

## 1. 队伍选择

加入后,队伍菜单会打开。

- **Visitors** 对所有人开放。
- **Malaysians** 需要 MYSverse 群组。

警察、消防、军队、出租车、HCC 和其他专业队伍需要群组权限、等级、白名单或 gamepass。查看 [队伍](/zh/bandaraya/teams)。

## 2. 首次出生

选择队伍后,你会出生在适合该队伍的位置。你可能拥有:

- 队伍工具,如果你的队伍发放任何工具。
- BR 钱包。
- 根据你的群组身份获得的 ID 或证件卡。
- 小地图和完整地图。
- 用于手机、地图和其他可用工具的顶栏图标。

## 3. 基本控制

| 按键 | 动作 |
| --- | --- |
| **WASD** | 行走 |
| **Shift** | 冲刺 |
| **Space** | 跳跃 |
| **E** | 与提示交互 |
| **F** | 坐在附近的座位上 |
| **在座位上按住 Space** | 离开座位 |

在移动设备上,使用屏幕上的控制并点击提示。

## 4. 试试看

### 驾驶

1. 找到一个出生点或 Classic Car Dealer。
2. 打开出生点面板。
3. 选择一辆车。
4. 坐在驾驶座上开车。
5. 如有需要,在 Radtrol 加油或在 Community Retail 充电。

查看 [车辆](/zh/bandaraya/vehicles)。

### 使用公共交通

1. 走到 MRT 或单轨车站。
2. 选择同一条线上的目的地。
3. 用 BR 或 CAG 付款。
4. 巴士方面,坐到乘客座位,车费会自动处理。

查看 [Bandaraya 交通](/zh/bandaraya/getting-around)。

### 赚取 BR

- **POS** 是最简单的入门工作。
- **出租车** 如果你拥有通行证或有队伍权限,效果不错。
- **拖车** 和 **巴士** 工作需要群组权限。

查看 [职业](/zh/bandaraya/jobs)。

## 5. 死亡、重置和重新加入

- 当你的生命值在 75 HP 或以下时,重置功能不起作用。
- 如果 KKM 或 SJAM 在值班,倒下的玩家有 5 分钟的失血窗口。
- 在被拘留或被逮捕时离开会在你返回时被自动监禁。

查看 [战斗与健康](/zh/bandaraya/combat-and-health) 和 [逮捕与法律](/zh/bandaraya/arrest-and-law)。

## 提示

- 如果队伍工具未出现,切换队伍后重新出生。
- 如果某个队伍缺失,你可能不满足权限要求,或当前没有人加入它。
- 留一些 BR 用于油料、过路费、罚款和紧急情况。
- 如果你计划经常乘巴士或快速旅行,请使用 CAG。
