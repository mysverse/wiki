# 开始体验 Bandaraya

**Bandaraya** 是 Roblox 上的马来西亚城市 roleplay 体验，场景设在吉隆坡。你会加入代表真实马来西亚机构的队伍 — 警察、消防、医疗、军队、交通、平民、王室 — 并在城市里生活。开车、工作、逮捕、救援、搭 MRT、到 mamak 点餐、塞在车龙里。由你选择。

游戏内货币是 **BR (Bandar Ringgit)**。本 wiki 中所有价格均以 BR 计算，除非另有标注 (R$ = Robux)。

## 你可以做什么

- **选择角色。** 平民、警察 (POLIS)、消防员 (BOMBA)、医生 (KKM)、士兵 (MAF)、巴士司机、出租车司机、邮差、塔台人员。每个队伍都有自己的工具、车辆和故事。
- **工作赚钱。** 送邮件 (POS)、开出租车、拖走违停车辆、驾驶巴士路线 — 或晋升警察职级，守护城市安全。
- **驾驶。** 25+ 个组织下有 200+ 辆车辆 — Proton、Perodua、Toyota、Honda、BMW，以及马来西亚特色紧急车辆车队。
- **出行。** 搭巴士 (坐下后自动扣车资)、通过 MRT Kajang Line 或 KL Monorail 快速移动，或开车经过 TapNGo 收费站。
- **买车。** 前往 Classic Car Dealer，选择车型、颜色，购买或租用，并保存到你的账号。
- **使用 CAG 卡。** Bandaraya 版 Touch n Go — 一张卡可用于巴士、MRT 和收费站，并有月票选项。
- **响应紧急情况。** 真实火灾事件、真实呼叫、真实病患。
- **被逮捕 (尽量别)。** POLIS 会拘留、上铐并逮捕你。冷却 3 分钟后，你会再次释放。
- **购物。** 食物、衣服、工具，甚至黑市。枪械需要 Firearms Licence gamepass。
- **Roleplay。** 游戏会奖励保持角色扮演的行为。

## 背景设定

Bandaraya 是游戏中的 **吉隆坡** 区域。你会认出真实地标 — **Maxis Tower**、**Grand Hyatt**、**Public Bank**、**PETRONAS** 区域、**Ampang Park**、**Bukit Bintang**，以及完整的 MRT/Monorail 网络，车站位于真实 KL 地点 (Conlay、Persiaran KLCC、Ampang Park；Bukit Bintang、Raja Chulan、Bukit Nanas)。

队伍是马来西亚风格机构：**POLIS**、**BOMBA**、**KKM**、**SJAM**、**RELA**、**MAF**、**KPTD**。交通卡 — **CAG** — 是 Bandaraya 的 Touch n Go 类似物，包括空卡欠费、月票，以及与 Deepavali、Merdeka 和 Raya 相关的收藏设计。

你在 Bandaraya 的前十分钟 — 从“我刚点了 play”到“我正在 KL 开车”。

## TL;DR

1. 在队伍菜单选择 **Visitors** 或 **Malaysians**。之后可以再换。
2. 生成进入。看看周围。
3. 用地图按钮打开地图 (它在 topbar 右侧)。
4. 缺钱？试试 [Postal Service 或 Taxi Driver](/zh/bandaraya/jobs)。
5. 想搭 MRT 或巴士？阅读[出行](/zh/bandaraya/getting-around)。
6. 想当警察？你需要加入 [POLIS group](/zh/bandaraya/teams#emergency-services)。

## 第 1 步 — 队伍选择菜单

加入游戏时，**队伍菜单**会自动打开。浏览 carousel。

- **Visitors** (亮绿色) — 对所有人开放，无要求。平民生活。
- **Malaysians** (亮黄色) — 需要加入 MYSverse 主 group (免费)。更“正式”的平民队伍。

点击 **Play** 生成。

警察、消防、军队等队伍需要 group 会员资格或 gamepass。完整列表和资格方式见[队伍](/zh/bandaraya/teams)。

## 第 2 步 — 第一次生成

你会出现在符合队伍的生成地点。看看周围。你有：

- 一个 **backpack**，里面有你队伍默认获得的任何工具 (平民没有)。
- 一个 **wallet** (BR) — 除非你之前玩过，否则从 0 开始。用 Roblox 标准 inventory 按钮打开。
- backpack 中有一张**驾驶执照**卡，带有合成的马来西亚 IC 号码 (`YYMMDD-14-<last4>`，其中 YYMMDD 是你的 Roblox 账号创建日期，14 是 WP KL 州代码)。
- 如果你在 MYSverse group 中，还会有 **MyKad** ID 卡。其他 group 会员资格 (POLIS、BOMBA、KKM、MAF、SJAM 等) 会额外发放服务专属 ID 卡。
- 一个**小地图** (默认右下角，也可按 **M** 切换完整地图)。小地图会用主标签显示你当前街名，并在下方显示 "Zone · Compass"。
- 一个 **topbar**，带有地图、手机和任何队伍专属 gadget 图标。

## 第 3 步 — 移动

- **WASD** — 行走。
- **按住 Shift** — 冲刺 (更快；受伤时更慢)。
- **Space** — 跳跃。
- **E** (或触屏点击) — 与 proximity prompt 互动 (门、kiosk、标志、按钮)。

## 第 4 步 — 试做一件事

任选一项：

### 开车
1. 找到 spawner — dealership 在 **Classic Car Dealer**，平民租车也从那里开始。
2. 互动，选择车辆，并使用屏幕按钮 (或 A/D + Space) 生成。
3. 坐进驾驶座。用 **W / A / S / D** 驾驶。**F1** 切换鼠标转向。
4. 燃油很重要 — 如果快没油，请前往 **Radtrol Gas Station @ Jalan Pinang** 或充电站。参见[车辆](/zh/bandaraya/vehicles)。

### 搭 MRT 或巴士
1. 走到**车站** (MRT 的 Conlay、Persiaran KLCC、Ampang Park；Monorail 的 Bukit Bintang、Raja Chulan、Bukit Nanas)。
2. 快速旅行面板会打开。选择目的地。用 BR 支付 (或用 CAG 卡 — 更便宜)。
3. 巴士方面，走进有标签的巴士，坐到乘客座位，车资会自动扣除。
4. 详情见[出行](/zh/bandaraya/getting-around)。

### 接一份工作
1. 查看[工作](/zh/bandaraya/jobs)。
2. **Postal Service (POS)** 最适合新手 — BR 稳定，不需要设置。
3. **Taxi Driver** 按行程付款，但需要 gamepass 或 Taxi Services 队伍。

### 只是放松
- 在 KL 走走。到 mamak 停一下。看一场逮捕。和 Twin Towers 自拍。

## 第 5 步 — 死亡、reset、重新加入

- **Reset** 按钮可用 — *除非* 你的生命值降到 75 或以下，那时它会变灰。这是刻意设计的，用来阻止玩家 reset 逃避逮捕 (RTAA)。参见[逮捕与法律](/zh/bandaraya/arrest-and-law#rtaa)。
- 如果你倒下但未死亡，medic (KKM 或 SJAM) 可以把你救起。当 KKM 或 SJAM 在线时，你有 5 分钟 bleedout 时间窗。
- 死亡后，你会在短暂 fade-to-black 后在队伍出生点重生。
- **被拘留时断线？** 那是 LTAA — 重新加入后你会被自动逮捕 3 分钟。参见[逮捕与法律](/zh/bandaraya/arrest-and-law#ltaa)。

## 第 6 步 — 前 10 分钟清单

- [ ] 已加入队伍 (Visitors / Malaysians)
- [ ] 已打开地图
- [ ] 已驾驶车辆 (任何车辆)
- [ ] 已购买或尝试赚取 BR
- [ ] 已参观地标 (Twin Towers？IPD Dang Wangi？mamak？)
- [ ] 已搭乘 MRT / 巴士 / 出租车

## 控制参考

### 移动

| 按键 | 动作 |
| --- | --- |
| **WASD** / 方向键 | 行走 |
| **Space** | 跳跃 |
| **Shift** (按住) | 冲刺 |
| **E** | 与 proximity prompt 互动 |
| **F** | 坐到最近的座位 (5 studs 内) — 开车、坐桌边、上巴士 |
| **按住 Space (坐在座位时)** | 离开座位 (必须按住 — 高速车辆会延迟离座；比轻点更安全) |

### 车辆

| 按键 | 动作 |
| --- | --- |
| **W / S** | 加速 / 刹车 |
| **A / D** | 转向 |
| **Shift** | 手刹 (许多 chassis 中) |
| **F1** | 切换鼠标转向 |
| **C** | 切换镜头 (部分车辆) |
| 喇叭 / 警笛按钮 | 紧急车辆中的屏幕按钮 |

### UI

| 按键 | 动作 |
| --- | --- |
| **Ctrl + W** | 打开你的 CAG 卡 wallet (随时) |
| **Z + Shift** (任意顺序) | 动作选择器 — 选择姿势：Sit、Surrender、Chilling、Injured、Leaning、Crossed Arms、Squat |
| **Escape** | 关闭大多数菜单 |
| **Shift + P** | 自由相机 (仅 admin — rank 251+ 或 whitelist) |

### 触控 (手机)

- 屏幕摇杆用于移动；跳跃 / 冲刺按钮在右侧。
- 点击 proximity prompt。点击车辆 UI 按钮。
- 车辆 spawner 支持手机 — 使用屏幕导航箭头。
- 某些互动在手机上更难；如果卡住，换设备或询问 mod。

## 提示与注意事项

- **你的队伍很重要。** 当前队伍决定你可用的 spawn、工具、车辆和 tablet app。
- **队伍会出现和消失。** 没有玩家的队伍会自动从队伍列表移除 (Visitors、Malaysians 和 Arrested 除外)。如果某个队伍消失，不用担心 — 有人加入时它会回来。
- **受伤时不要 reset。** 它为了你好而被禁用 (anti-RTAA)，也防止你作弊逃离逮捕。
- **使用 CAG 卡。** 如果你会多次使用公共交通，花 100 BR 很值得。
- **阅读规则。** 参见[规则](/zh/bandaraya/rules)。
