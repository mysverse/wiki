# 通行证与加成

本页汇总了加速 Lebuhraya 进度的方法：游戏通行证、Roblox Premium、季票和特别活动。

## 团队游戏通行证

五支队伍被锁定在游戏通行证后面。购买通行证可以让您从 Main Menu 永久访问该团队。

|团队|它给你什么 |
|---|---|
| **Taxi Driver** |加入Taxi Driver团队，驾驶NPC乘客赚取车费。出租车车型通过职业等级解锁。 |
| **Bandaraya** |捆绑通行证 - 包括 Taxi Driver 访问权等。 |
| **KEMRonda** |高速公路辅警通道。拖车、道路救援工具。 |
| **Bomba** |消防和救援通道。消防车、水龙带、吊具、链锯。 |
| **Polis Trafik** |交警通行。泰瑟枪、雷达枪、警车。 |
| **Undercover Police** |无标记的执法通道。与Polis Trafik相同的工具包。 |

这些游戏通行证是在Robux中一次性购买的。在体验的“商店”选项卡中或从相关机构大楼的 NPCs 中查找它们。

## XP 提升gamepass

您所做的一切都会永久 **+50% XP**。与所有其他 XP 乘数 - Premium、车队、代币、Double XP 周末叠加。

对于计划长期玩Lebuhraya的玩家来说，这是最超值的游戏通行证之一。

## 工作坊gamepass

解锁Bandar Seri Putra **Gravstone Workshop** 处的涂装和车身自定义菜单。有了它，您可以通过实时颜色选择器为车身、车窗、轮胎和轮辋重新着色。如果没有它，工作室会提示您购买，然后再让您更改任何东西。

## 其他gamepass福利

较小的游戏通行证和Robux优惠可能存在于：

- 特殊车辆或车辆类别
- 化妆品
- VIP server 设施
- 车间或设施使用权

检查游戏内商店的当前列表。

## Roblox Premium

Roblox Premium 订阅者会自动在 Lebuhraya 中获得永久 **+25% XP** - 无需激活。这与其他所有提升叠加。如果您已经订阅了 Roblox Premium，那么您实际上始终处于 ×1.25。

## 季票

Lebuhraya 运行**季票**：限时进度曲目，并提供分级奖励。

### 季票如何运作

- 每个季节持续一段固定的时间（通常为 5-6 周）。
- 您通过完成任务赚取 **Season XP** - 与现有游戏活动相关的简短目标挑战。
- 您清除的每个等级都会授予**奖励** - 通常是化妆品、代币或（历史上）解锁团队的快捷方式。
- **Premium Track** 为每个等级解锁并行奖励路径。免费玩家获得免费奖励； Premium持有者可获得免费奖励和高级奖励。

### 最近一季：Season 2“Lebuhraya”

Season 2 于**2026 年 3 月 20 日至 2026 年 4 月 30 日**（马来西亚）运行，并有 **20 个等级**。奖励集中在 XP 掉落、2× XP 和季票提升代币、团队访问代币、badges（如 **Season 2 Pioneer**）、头衔和可解锁涂料（如 **Copper Kampung**）。

### Season 1 旧版解锁

之前的Season 1通行证为完成它的玩家提前解锁了三支球队：

- **Waste Disposal**（通常是25级 - 有些游戏中的UI仍然说是50级）
- **后勤**（通常为75级）
- **Lumberjack**（通常等级150）

在 Season 1 期间获得这些解锁的玩家将永久保留访问权限。新赛季使用不同的奖励，因此当赛季处于活动状态时请检查游戏内的赛季菜单。

## 代币

令牌是存储在您的库存中的消耗性增强物品，需要手动激活。完整列表请参见[社交功能 → 代币和提升](/zh/lebuhraya/social-features#tokens-and-boosts)。

最值得注意的是：

- **2× XP Boost** 代币 - +100% XP 在设定时间内
- **Team Access Pass** - 临时访问gamepass锁定的团队
- **2× Season Pass 提升** - 双倍 Season Pass XP 收益

## Double XP 及免费试用活动

该游戏会定期举办与马来西亚文化节日和 MYSverse 里程碑相关的 **2X XP 活动**。当活动进行时，每个玩家的基础XP乘数将变为×2 - 除了Premium、车队、gamepass和代币提升之外。

每个 2X 活动还会激活 **Gamepass Trial**：在活动期间，您可以**免费临时访问高级 gamepass 团队**。审判开始和结束时，游戏会显示横幅。

过去的活动包括：

- **LebuhRAYA推出**（三月下旬至四月初）
- **发布后扩展**（四月下旬）
- **WESAK**（Vesak Day，五月中旬）
- **Season Pass更新**（五月底/六月初）
- **马来西亚日**（九月中旬）
- **Deepavali**（十月中旬）
- **新年**（十二月底至一月初）
- **Chinese New Year / CNY**（通常为一月底至三月初）
- **Hari Raya / 开斋节**（三月下旬）

日程安排遵循实际的马来西亚公共假期日历，因此预计大约每 1-2 个月就有一场活动。观看 MYSverse 的社区频道 - Rafahia App、Discord 或游戏内横幅通知 - 了解公告。

## 堆叠的数学原理

这是一个最大的 XP 场景：

- 底座：×1
- Double XP 周末：×2（这取代了基本乘数）
- XP Boost gamepass：+0.5
- Roblox Premium：+0.25
- 代币XP Boost：+1.0
- 同一团队的朋友的完整车队：+0.5
- **总乘数：约×4.25**

通常达到 12 级需要达到 50 级。在认真的磨练过程中使用这些。

## 挑战和成就

**挑战**系统（可从 **Main Menu -> 活动**访问）会奖励您玩游戏的日常活动。存在三个类别：

### 每日挑战（每 24 小时重置一次）

这三个目前都处于活动状态：

- **每日司机**（旅行者）- 驾驶距离目标
- **周末渔夫**（钓鱼）- 捕获许多鱼
- **Konvoi Harian** - 花时间在车队中

### 每周挑战（每 7 天重置一次）

七个每周模块中的五个目前处于活动状态；本赛季有两人被禁用：

- **耐力车手**（旅行者）
- **成功的渔夫**（钓鱼）
- **康沃名官**
- **测验大师（高级）**
- **单圈时间传奇** - 单圈时间
- *测验大师（基本）- 目前已禁用*
- *单圈时间图例（高级）- 目前已禁用*

### 发现成就（一次性、永久）

35 个一次性目标涵盖基础知识和里程碑。亮点：

- **首次驾驶** - 您第一次坐在车内的时刻
- **Jalan Jalan** - 漫游地图
- **Anak Murid** - 参观学校
- **Cari Kerja** - 尝试你的第一份工作
- **Bayar Tol** - 通过收费站
- **Penghantar Makanan** - 完成食品配送
- **Penebang Kayu** - 砍柴
- **Pemandu Teksi** - 完成出租车任务
- **Pemandu Lagenda** - 驾驶距离残局

另外还有成就badges，例如公路传奇级别里程碑、马拉松车手、垂钓大师、速度恶魔、Pembalap、车队之王、万事通、Warga Sejati 等等。

## 可解锁的奖励

除了您的等级和职业排名之外，还有一个包含**42 个可解锁物品**的单独目录可跟踪外观进展。通过季票、活动、代码和成就获得。三种类型：

- **12 种车辆油漆** - 颜色、渐变和纹理变体（例如 Chrome Silver、Matte Black、Neon Green、Copper Kampung）。拥有兼容喷漆的汽车时，可从车辆定制菜单中应用。
- **17 个标题** - 装饰开销标签。选择一个显示在您的角色上方。目前的名单包括：Highway King、Ilmuwan、Jurumudi Handal、Legenda Musim 2、Nelayan、OG Musim 2、Pemandu Baru、Pemandu Teksi Pro、Pembalap、Penghantar Setia、Penjelajah Agung、Penunggang Laju、 Raja Lebuhraya、Raja Tol、Road Legend、Road Warrior、Warga Sejati。
- **13 个收藏品 badges** - 装饰性 badges （例如“Pemandu Season 2 专用”）显示在您的个人资料上。

活动解锁会按玩家保存 - 您可以保留在会话中获得的所有内容。

## Roblox badges 行驶距离

当您超过里程里程碑时，将自动奖励四个真正的Robloxbadges：

|行驶距离|徽章|
|---|---|
| 50,000 studs | 50k 徽章 |
| 100,000 studs | 10 万徽章 |
| 500,000 studs | 50 万徽章 |
| 1,000,000 studs | 1m 徽章 |

随着距离计数器的增加，徽章会自动授予。您无需认领它们。

还跟踪比赛获胜里程碑，例如 1、10、50 和 100 场胜利，以获得未来的奖励。

## 即时级别Robux购买

如果您想跳过研磨级别，Lebuhraya提供四次一次性**Robux购买**。这些会立即提供平坦的等级提升 - 如果您正在追逐特定等级门控的团队（例如，200 级的Kesihatan），则非常有用。

|产品 |效果|
|---|---|
| +1 级 | 1级，无论你需要跨越什么门槛|
| +10 级 | 10 个级别 |
| +25 级 | 25 个级别 |
| +50 级 | 50 个级别 |

奖励等级上限为最高等级 (500)。 XP 授予**绕过乘数堆栈** - 精确的级别跳跃，毫不奇怪。在游戏内商店或通过Main Menu找到它们。

## 首先买什么？

如果您已经玩了几天并且想要投资：

1. **XP Boost gamepass** - 性价比最高的XP加速。永恒的。
2. **你喜欢的gamepass队伍** - Bomba和Polis Trafik最受欢迎，因为999系统很好玩。
3. **Season Pass** (Premium Track) - 只有当你在赛季中积极玩游戏并想要特定奖励或早期工作解锁时才值得。

如果您订阅了其他游戏的 Roblox Premium，那么这已经对您有用了 - 无需额外支出。
