# 操作

Lebuhraya 支持键盘、手柄、触屏和 VR。游戏会自动检测你的平台并在游戏内显示对应的提示。若屏幕上显示了某个操作提示，请直接使用它。以下参考列出了常见按键绑定的样式。

## 进出车辆

站在驾驶座或乘客座**6 格**范围内。

| 平台 | 按键 |
|---|---|
| 键盘 | **F** |
| 手柄 | **X**（手柄正面按键） |
| 触屏 | 点击屏幕上的**驾驶** / **坐下**按钮 |
| VR | **右扳机 (R2)** |

相同操作可退出座位。

### 座位权限

驾驶座通常锁定给车辆的拥有者。若你尝试坐进他人的车，除非对方已为你解锁，否则将被阻止。

## 驾驶

大多数车辆使用以下默认驾驶操作：

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 加速 | **W** | 右扳机 (RT) |
| 刹车 / 倒车 | **S** | 左扳机 (LT) |
| 向左转 | **A** | 左摇杆 |
| 向右转 | **D** | 左摇杆 |
| 手刹 | **空格** | A / RB |
| 切换转向灯 / 车灯 | **E**、**Q**、**I**、**J**、**H**（因车而异） | 查看游戏内提示 |
| 喇叭 | **H**（多数车辆） | 按下右摇杆 |

::: info
游戏中新旧底盘系统的车灯操作有所不同。请始终依照当前所驾车辆的屏幕提示操作。
:::

## 步行

标准 Roblox 操作。

| 动作 | 键盘 | 手柄 | 移动端 |
|---|---|---|---|
| 移动 | **W / A / S / D** | 左摇杆 | 屏幕虚拟方向键 |
| 跳跃 | **空格** | A | 跳跃按钮 |
| 冲刺 | （游戏内已启用按 Shift 跑步） | 按下左摇杆 | 冲刺切换 |
| 镜头 | 鼠标 | 右摇杆 | 滑动 |

### 近距离提示

大多数世界互动使用 Roblox ProximityPrompts：载具生成器、门、工作柜台、油泵、修理区、拖车面板和商店柜台。

- 站得足够近以使提示出现。
- 若有按住时长要求，按住所示按键/按钮直至圆圈完成。
- 若提示显示你所在队伍错误或油泵类型不符，说明提示正常运作，请按照警告操作。

### 主菜单选项卡

打开主菜单可访问：

- **主页** - 公告与概览
- **队伍** - 选择 / 切换队伍
- **商店** - 游戏内购（gamepass 提示、tokens）
- **活动** - 任务、挑战和 Season Pass 进度
- **更多** - 卡片网格，包含：
 - **职业** - 你的职业等级和机构进度
 - **工作** - 各分支等级条和奖励
 - **Tokens** - 你的活跃和储存的 tokens / 加成
 - **制作人员** - 开发团队与贡献者
 - **比赛** - 计时赛和 PvP 竞速菜单
 - **帮助** - 可用时的教程

职业、工作、Tokens、制作人员、比赛和帮助均归入**更多**之下。

### 可调整的设置

打开设置面板（主菜单中的齿轮）可切换以下选项：

- **碰撞系统** - 在可用时开启车辆损坏。激活期间给予 **+15% XP**，但严重碰撞可能使你受伤。
- **头顶等级** - 显示或隐藏浮于角色上方的队伍等级/称号。
- **第一人称视角** - 切换镜头模式。游戏内按正斜杠（`/`）可切换视角。
- **载具生成器：新版** - 选用刷新后的载具生成器界面。
- **手刹**按键 - 重新绑定手刹键位。
- **Shift + C** - 切换整个 HUD（适合截图）。
- 重置 / 更换 / 移除 - 重新定位与自定义快捷方式。

### 屏幕顶部指示器

- **活跃 tokens** - 显示正在运行的加成及其剩余时间。
- **状态显示** - 驾驶时显示速度、油量、GPS 方向和健康信息。
- **排行榜** - 显示在线玩家、其队伍、等级和行驶距离。可点击某行以查看 Roblox 社交选项。

## 工具（工作装备）

当你持有工具时 (斧头、雷达枪、电击枪、寻呼机、消防水管),操作因工具而异。请使用屏幕提示或查看相应队伍的工作页面。

## 移动端技巧

- 游戏适配移动端布局；手机上驾驶可行，但平板电脑上更为方便。
- 大多数 ProximityPrompts（进门、与 NPC 交谈、开始工作）会在屏幕上显示圆形按钮，点击即可。
- 驾驶时，方向盘位于 HUD 左侧。
- 避免按住屏幕底角用于非驾驶 UI，那里是 Roblox 的移动摇杆和跳跃按钮。
- 若卡片网格或菜单感觉拥挤，将设备旋转至横屏模式。主菜单的更多和队伍视图专为短横屏设计。

## 手柄技巧

- 菜单按钮可选中。若焦点丢失，关闭并重新打开菜单，游戏将重新选中第一个按钮。
- 使用方向键/左摇杆在卡片间移动，**A** 确认，**B** 在 UI 显示返回或关闭动作时退出。
- 部分旧版 Roblox 面板仍依赖光标式选择，若感觉别扭，暂时切换到鼠标/触屏即可。

## 无障碍功能

- Roblox 全局系统设置有效 - 色盲滤镜、UI 缩放、文字转语音。
- 可切换被动模式以阻止工具和武器互动。若不希望被卷入战斗或紧急情境扮演，此功能非常实用。
