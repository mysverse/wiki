## 主菜单

加入 Sumaya 时,你会在出生前看到主菜单画面。从这里你选择一个**队伍**,它决定你扮演什么角色 - 普通市民、警察、消防员或医护人员。你选择的队伍会影响你开始时获得的工具和你能做的工作。

你可以稍后更换队伍。第一次选择不会永久固定。选择你觉得有趣的就行。

准备好后,按 **Jom**(马来语"出发吧")进入世界。

在加载或队伍切换期间,Sumaya 可能会显示带有马来西亚轮播事实的黑色加载遮罩。游戏准备好后会自动消失。

### 开放测试通知

每次游戏中你的角色第一次出生时,你可能会看到一个 **Open Beta** 免责声明,说明:

- 随着游戏开发,功能可能会发生变化。
- 玩家数据可能会定期重置以保持经济平衡。

点击 **I understand** 关闭它。该通知在同一会话中不会再次出现。

## 商店和 gamepass

Main Menu 有一个 **Shop** 标签，你可以在那里购买 Robux gamepass 和一次性现金包。目录包含当前可用的 **Retro Vehicles** 包，以及多个用于高级车辆和 POLIS 角色包的 **Coming Soon** 条目。完整列表请参见 [商店与游戏通行证](/zh/sumaya/shop)。

## 选择队伍

有五个队伍。其中三个(POLIS、BOMBA、Kesihatan)是有特定职责的紧急服务。另外两个(Visitors 和 Malaysians)让你扮演普通人。

| 队伍 | 他们做什么 | 任何人都能加入吗? |
|------|--------------|------------------|
| Visitors | 普通市民,默认选项 | 是 |
| Malaysians | 普通市民,已验证群组成员的装饰队伍 | 只有 MYSverse 群组 3 级以上成员 |
| POLIS | 警察:逮捕罪犯、巡逻、执行限速 | 是 |
| BOMBA | 消防:扑灭火灾、进行救援 | 是 |
| Kesihatan | 医疗:治疗伤员、运营医院 | 是 |

查看 [队伍](/zh/sumaya/teams) 了解每个队伍的更多细节,包括你开始时获得的工具。

**不确定选哪个?** 从 **Visitors** 开始。你可以立即尝试民用工作(钓鱼、mamak、棕榈油)或短期零工,然后在熟悉环境后切换到紧急服务队伍。

## 你的初始资金

每位新玩家都从以下开始:

- 钱包里 **100 Ringgit**
- 银行里 **1000 Ringgit**

这足够买几样商店物品和基本支出,但不够付费租车或买房。先用一辆免费的起始车;Tier 1 住房从 **25,000 SR** 起。查看 [经济](/zh/sumaya/economy) 了解更多关于钱的内容。

## 控制

Sumaya 使用标准 Roblox 移动。在 PC 上:

| 动作 | 按键 |
|--------|-----|
| 移动 | W, A, S, D |
| 冲刺 | Left Shift(按住) |
| 跳跃 | Space |
| 与提示交互 | E(出现提示时) |
| 打开手机 | 屏幕上的手机按钮,或点击图标 |
| 聊天 | /(斜杠)聚焦聊天栏 |

在移动设备和手柄上,屏幕按钮和标准 Roblox 手柄绑定按预期工作。

## 教程弹出窗

你第一次走进某些地方(车辆经销商、Mamak 柜台、快餐柜台、棕榈种植园、拖网钓鱼码头等)时,Sumaya 会显示一次性的**教程信息图**:一个解释该系统如何工作的小型插图面板。你点击翻页并关闭它。

每个教程每账户只触发一次。没有应用内方式重新打开已关闭的教程;手机应用 [Jelajah](/zh/sumaya/phone) 的 **Baca Maklumat** 按钮会重新打开**地标**信息图,而不是教程。

## 你的头五分钟

下面是你出生后应该立即做的事:

### 1. 打开手机

手机是你的主要枢纽。点击屏幕上的手机图标打开它。你会看到职业、任务、紧急通话、设置等应用。完整列表请查看 [手机与界面](/zh/sumaya/phone)。

打开手机也算作你第一个任务的一个步骤。

### 2. 查看任务应用

你会自动开始 **Welcome to Sumaya** 任务链:12 个任务教你基础知识,并随着进度支付 XP 和 Ringgit。每个任务都会告诉你下一步要做什么。

打开手机上的 **Quest** 应用查看当前目标。红色引导光束和小地图上的标记通常会指向正确的地方。完整链请查看 [任务](/zh/sumaya/quests)。

### 3. 生成一辆车

走到任何 **车辆生成器 kiosk**(在城里寻找散布的提示)。选择一辆车,租或买,然后开走。免费起始车是 **Perosatu Axia** 和 **Protan Wira**;其余标准民用目录需要 Ringgit 来租或买。

查看 [车辆](/zh/sumaya/vehicles) 了解完整列表以及生成器如何工作。

### 4. 开始一份民用工作

走到任何**职业站**(钓鱼码头、mamak 摊位、棕榈种植园),按交互提示打卡。你也可以在零工可用时接短期零工,比如 E-Hailing、包裹递送、拖车、报告、导游和餐厅供应跑单。工作时你会赚取 Ringgit 和 XP。工作描述在 [职业概览](/zh/sumaya/jobs)。

如果你选择了紧急服务队伍(POLIS、BOMBA、Kesihatan),你不需要打卡 - 你一出生就在值班。

### 5. 探索

走、开或飞着到处看。有地图、地标、商店、医院、警察局、消防站、海滩和很多社区。小地图(屏幕右上角)显示你周围有什么。

一些世界道具即使不属于任务也是可互动的。钓鱼区的运输垫可以让你在陆地和浮桥之间移动,一些咖啡机让你冲泡和带走咖啡。

## HUD 概览

当你在世界中时,你会看到:

- **小地图**(右上角):显示你的位置、附近的道路和建筑、路径点,以及当任务指向某处时的红色引导光束。点击展开。
- **状态控件**(右上角,小地图下方):你的 **Citizen 等级** 和进度条,加上显示活动行业的第二行(紧急服务的等级,民用班次的等级 / 最大值)。
- **任务卡**(左上角):显示你当前的目标(活动任务步骤、当前火灾、你正在治疗的患者等)。如果挡路,点击 V 字符号将其折叠。
- **Topbar 图标**(顶部中央):小的 Map / Tasks / Status / Open Menu 图标。点击任何一个隐藏该 HUD;点击 **Open Menu**(房屋图标)在游戏中无需死亡即可重新打开主菜单。
- **钱包/银行余额**:在屏幕顶部附近可见。

## 冲刺

按住 **Left Shift** 或 **Left Control** 冲刺。步行速度为 10 studs/s;冲刺将其翻倍至 20。当前版本没有体力限制 - 你可以一直冲刺。

进入车辆座位时冲刺会自动关闭。

## 起始工具

每个玩家出生时背包里有五件工具:

| 工具 | 它做什么 |
|------|--------------|
| **Phone** | 打开手机界面(应用、任务、MDT、999 通话、设置等)。游戏中使用最多的工具。 |
| **Wallet** | 持有你的现金。装备它在另一个玩家附近以提供 **Sadaqa** 捐赠,或将其掉在地上用于角色扮演。查看 [经济](/zh/sumaya/economy)。 |
| **Torchlight** | 带方向光束的手持手电筒。在夜间、黑暗内部或角色扮演场景中很有用。 |
| **Firecrackers** | 一个角色扮演派对工具,带声音和粒子点燃和爆裂。不会伤害任何人;纯装饰。 |
| **infinite cheese burger** | 角色扮演食物道具。"infinite" 标签是有意的;装备并使用以咀嚼。当前版本未激活饥饿系统,所以它不恢复任何东西。 |

紧急服务队伍(POLIS、BOMBA、Kesihatan)在此基础上获得额外工具。查看 [队伍](/zh/sumaya/teams)。

## 接下来做什么?

- 选择一个 [队伍](/zh/sumaya/teams) 和 [职业](/zh/sumaya/jobs)。
- 阅读 [手机和界面](/zh/sumaya/phone) 这样你就知道东西在哪里。
- 查看 [任务链](/zh/sumaya/quests) 获得结构化的演练。
- 准备好赚真钱时,查看 [经济](/zh/sumaya/economy) 了解最高薪工作在哪里。
