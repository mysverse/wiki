# 商店与游戏通行证

Sumaya 有两种不同的“商店”。本页同时介绍两者：

1. **Main Menu Shop** 标签，你可以在这里用 **Robux** 购买 gamepass 和现金包。
2. **世界内商店**，你可以在城里的摊位用 **Ringgit** 购买食物、油罐和工具。

两者都向所有玩家开放。

## Main Menu Shop 标签

打开 Main Menu（可从加入画面打开，或通过顶部栏的 **Open Menu** 房屋图标打开），然后点击 **Shop** 标签。你会看到一组卡片：上方是 gamepass，下方是一次性现金购买。

每张卡片显示标题、简短说明，以及 **Purchase** 按钮或 **Coming Soon** 标签。Coming Soon 卡片预览团队仍在制作的内容：图片、名称和说明可见，但在物品准备好之前无法购买。

### 现在可以购买的内容

| 物品 | 类型 | 你会获得什么 |
|------|------|--------------|
| **Retro Vehicles** | Gamepass | 在标准平民车商解锁经典 / 复古车包：**Protan Saga 1985**（免费）、**Merzda Miata**（12,000 SR）、**Nisun S15 Silvia**（20,000 SR）、**Joguar XJ308 R**（29,000 SR）。未拥有者可以看到被 gamepass 提示锁住的卡片。参见 [车辆](/zh/sumaya/vehicles)。 |

### 即将推出

这些卡片现在会显示在商店中，但购买按钮已停用。团队完成 gamepass / 商品 ID 后，它们会正式上线。

| 物品 | 类型 | 计划效果 |
|------|------|----------------|
| **Income / Job XP Booster** | Gamepass | 对符合条件的职业和公共服务工作给予 +25% 工作 Ringgit 和 +25% 工作行业 XP。**不会**提升玩家等级 XP、任务奖励、犯罪报酬、ATM 转账、捐赠/Sadaqa、退款，或商店 / 车辆 / 房屋购买。完整适用列表请参见 [经济](/zh/sumaya/economy)。 |
| **Car Radio / Boombox** | Gamepass | 精选车载电台和近距离 boombox。自定义音频 ID 仍保持停用。 |
| **Premium EV Vehicles** | Gamepass | 向平民车商加入高级电动车包。 |
| **Premium Sports Vehicles** | Gamepass | 加入高级跑车 / 超跑车包。 |
| **Premium Luxury Vehicles** | Gamepass | 加入高级豪华车包。 |
| **Expanded POLIS Vehicles** | Gamepass | 为已经在 POLIS 队伍的玩家提供额外 POLIS 车队条目。 |
| **Traffic POLIS Role** | Gamepass | 专注于雷达和道路管制道具的 POLIS 专门化。你仍在普通 POLIS 队伍中使用，不是单独队伍。 |
| **Unmarked POLIS Role** | Gamepass | 用于无标识车辆和车牌检查调查的 POLIS 专门化。没有额外逮捕权力。 |
| **Cash Pass SR5,000** | 一次性购买 | 将 5,000 Ringgit 存入你的银行。 |
| **Cash Pass SR25,000** | 一次性购买 | 将 25,000 Ringgit 存入你的银行。 |
| **Cash Pass SR100,000** | 一次性购买 | 将 100,000 Ringgit 存入你的银行。 |

如果团队在你游戏时加入最终 ID，Coming Soon 标签会在下次商店加载时自动变成 **Purchase**。你不需要做任何事；回来查看即可。

### Gamepass 如何保留

- Gamepass 所有权绑定到你的 **Roblox 账号**，所以它会跟随你进入每个 Sumaya server 和每次游玩。
- 一次性现金购买会直接进入你的 **银行账号**，并带有类似工资的通知。它们按收据追踪，因此重复购买通知不会让你重复收款。
- 拥有车辆 gamepass 会在普通车商解锁相关车辆；你仍要支付游戏内 **Ringgit** 价格（大多数不是免费的）。
- 如果你在 Coming Soon 卡片上线前已经拥有旧版车辆包（Premium、Supercar、EV、KEMRonda、Traffic POLIS、Unmarked POLIS、Classic / Retro），该所有权仍会生效；你不需要重新购买。

### 退款和争议

游戏内 gamepass / 现金购买通过 Roblox 正常 Marketplace 进行，因此退款和付款争议由 Roblox 支持处理，而不是 Sumaya 团队。

## 世界内商店（Ringgit）

世界内商店让你用 Ringgit 购买消耗品、工具和角色扮演物品。它们分布在地图各处，并会标在 minimap 上。

### 食物摊

便宜食物物品，目前只是装饰 / 角色扮演风味。它们在当前版本中不会真正恢复饥饿。

- **Mamak Stall**：Kopi Tenom 和 Teh Tarik 等饮料，以及简单餐点。
- **Nasi Lemak Stall**：一小份马来西亚经典菜单（Nasi Lemak、Nasi Goreng、Roti Canai、Milo Ais）。

每件物品价格为 1 到 5 SR。

### 船用油罐商店

出售钓鱼拖网船的补给油罐。汽车不需要加油。

| 油罐 | 补充量 | 价格 |
|-----|--------|-------|
| 红色 | +25 燃料 | 75 SR |
| 绿色 | +50 燃料 | 100 SR |
| 黑色 | +75 燃料 | 125 SR |

拖网船燃料上限为 100，且**只有当前燃料低于 75 时才能补充**，所以快满的油箱补充不会生效，也不会消耗油罐。

### 工具和消耗品

犯罪工具（Slim Jim、Pickpocket Knife）由 **Abang Samseng** NPC 免费发放，而不是在商店出售。参见 [犯罪与法律](/zh/sumaya/crime-and-law)。

## 小贴士

- **每次游玩都浏览商店标签。** 当团队完成设置后，Coming Soon 卡片会安静地变成 Purchase 卡片；游戏内不会另行通知。
- **Retro Vehicles 包是你现在唯一能购买的付费包。** 在 Premium EV / Sport / Luxury 包上线前，标准平民车商是你唯一的付费车辆来源。
- **现金包是银行到银行。** 它们会进入你的银行，所以 500 SR 钱包上限不重要。你可以把现金包直接存进银行，为大额购买储蓄。
- **世界内摊位食物目前只是装饰。** 不要期待 Teh Tarik 恢复体力；当前版本还未启用饥饿 / 体力 HUD。
- **油罐只给船补充燃料。** 汽车没有燃料限制。
