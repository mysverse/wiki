# 车辆

Sumaya 拥有庞大的车辆目录：民用车、Classic Car Pack 车辆、捕鱼拖网船、警车、Bomba 消防车与救护车。本页介绍如何生成它们、附带价格的完整目录，以及如何个性化与维护它们。

## 如何生成车辆

在城内寻找**车辆生成器站**。它们以互动提示形式出现在街角、车行与各个站点。

1. 走到生成器旁，按下互动提示。
2. 车辆菜单会打开，显示你可使用的车辆。
3. 选择一辆。你将看到它的名称、价格与要求。
4. 选择**租用**或**购买**：
   - **租用**：支付较小的一次性费用，当你重生、登出或生成另一辆车时，车辆会消失。
   - **购买**：支付全额价格，车辆将永久属于你（并跨场次保留）。

### 如果车辆变灰怎么办？

如果你无法生成某辆车，生成器会告诉你原因。通常是以下其中之一：

- **玩家等级过低**（你需要更高的玩家等级）。
- **部门等级过低**（适用于团队车辆，例如 Bomba Sanica Tanker 需部门等级 65）。
- **错误的团队**（警车需 POLIS 团队，等等）。
- **你已经有一辆工作车辆**（例如捕鱼时已有拖网船）。

民用车生成器只显示民用车，团队生成器只显示团队车辆，捕鱼船生成器只显示拖网船。

## 捕鱼拖网船

拖网船在码头的捕鱼船生成器处生成，且只有在你登记进入**捕鱼部门**时才会出现。请参阅 [Fishing](/sumaya/jobs-fishing)。

| 拖网船 | 价格 |
|---------|-------|
| Tier 1 Trawler | 免费（前提是你在捕鱼班次中） |
| Tier 2 Trawler | 25,000 Ringgit |

更高的 tier 可承载更多鱼。

## 紧急警笛（ELS）

Polis、Bomba 与 Kesihatan 的车辆都装备了 **Emergency Lighting System (ELS)**。在驾驶紧急车辆并启动警笛时：

- 你拥有**闪烁的红/蓝/白灯**。
- 你**豁免违规**——超速与撞车都不计入。
- 其他玩家会收到音频/视觉警告，知道你正在驶来。

停车时关闭警笛。豁免仅在你实际驾驶且警笛启动时生效。

## 个性化定制

具有 `Color = true` 的民用车辆支持颜色定制。生成车辆时或在你的车辆资料中查找 **Paint / Customize** 选项。你可以更改：

- **车身颜色**——车辆的烤漆。
- **轮辋颜色**——车轮轮辋（前提是该模型有标记轮辋部件）。
- **车窗着色**——任意 `Color3`，应用于标记为 `VehicleWindow` 的部件。

某些车辆（**Protan Wira**、**Protan Saga**、**Perosatu Axia**、**Perosatu Myvi 2020**）有预设调色板（例如白、银、黑、红、米色）。其他可定制车辆接受任何颜色。

团队车辆通常不可定制。

## 燃料

Sumaya 目前的燃料实际上**无限**——你无须担心耗尽燃料或在加油站加油。船上的燃料表按班次追踪（适用于捕鱼拖网船），但车辆没有燃料限制。

## 碰撞切换

从你的 **Phone > Collision** 应用中，你可以切换车辆碰撞开或关。当碰撞关闭时：

- 你的车辆会**穿过**其他车辆。
- 适用于从狭窄停车位脱身或被其他玩家撞击时。
- 当你想要正常驾驶时再开启碰撞。

更多 Collision 应用相关信息请参阅 [Phone and UI](/sumaya/phone)。

## 进入车辆时的镜头

当你坐进或离开车辆时，镜头现在会平滑过渡到驾驶视角，而不是突然跳转。游戏会自动为桌面、平板和移动端控制调整取景，因此你不需要更改设置。

如果你正在使用另一种镜头模式，例如手机的 Cinematic 应用，该模式会保持优先级，直到你关闭它。

## 所有权与持久性

- **租用的车辆**会在你重生、登出或生成另一辆车时消失。
- **购买的车辆**永久属于你。它们会显示在你的资料的 Owned Vehicles 列表中。
- 如果你购买了车辆并日后想出售，请查看生成器——某些车辆可能可以出售以获得部分退款（视情况而定）。
- 如果你拥有的车辆被他人**劫持**，它会在车牌数据库中被标记为失窃，Polis 可以追回。

## 车牌与登记

每辆车都有**车牌**。当你生成车辆时：

- 车牌会绑定到你的用户 ID 作为登记车主。
- POLIS 可以从 MDT 查询任何车牌以查看车辆所有者。
- 如果你的车辆被偷，车牌状态会标记它。

## 小贴士

- **先租后买。** 在投入 5,000+ Ringgit 之前，先以租用价格试试一辆付费车。
- **随等级升级你的团队车辆。** 更高 tier 的 Bomba 与 Polis 车辆更快、更耐用。
- **警察和消防员的警笛 = 无罚单。** 出勤时务必开启警笛，免得自己罚自己。
- **不要停在车道上。** 留下的民用车可能被劫持；若你拥有它且不想被偷，请停在更安静的地方。
- **停车用穿越模式。** 若有人挡住你，启用碰撞切换便可穿过他们。
- **存钱买 Tier 2 或 3 拖网船。** 若你认真投入捕鱼，更大的船很快就能回本。
