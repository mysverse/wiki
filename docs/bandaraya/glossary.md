# Glossary - malaysian terms & game acronyms

Bandaraya uses Malaysian organisations, places, and roleplay shorthand. Use this page when a term is unfamiliar.

## Money and travel

| Term | Meaning |
| --- | --- |
| **BR** | **Bandar Ringgit**, Bandaraya's in-game currency. |
| **CAG** | **Click And Go**, the stored-value transit card for buses, MRT/Monorail, and toll discounts. |
| **TapNGo** | Highway toll gate system. CAG gives a toll discount when your card can pay. |
| **MRT** | Mass Rapid Transit. Bandaraya has MRT fast travel on the Kajang Line. |
| **Monorail** | KL Monorail fast travel line. |

## Organisations and teams

| Acronym | Full name | Meaning in game |
| --- | --- | --- |
| **POLIS** | Polis MYSverse | Police. Handles patrols, arrests, traffic, summons, and BOLOs. |
| **PB** | Polis Bantuan | Auxiliary transit police for MyTransit. |
| **BOMBA** | Bomba MYSverse | Fire and rescue. |
| **KKM** | Kementerian Kesihatan MYSverse | Health ministry and medical response. |
| **SJAM** | St. John Ambulans MYSverse | Volunteer ambulance service. |
| **RELA** | Ikatan Relawan Rakyat | Volunteer support force. |
| **MAF** | MYSverse Armed Forces | Military team. |
| **KPTD** | Kor Polis Tentera MYSverse | Military police. |
| **JIM** | Jabatan Imigresen MYSverse | Immigration department. |
| **NWS** | National Wire Services | In-game news agency. |
| **OCG** | Organised Crime Group | Approved criminal roleplay groups. |
| **HCC** | High Class Citizen | Premium civilian team. |
| **SPAD** | Suruhanjaya Pengangkutan Awam Darat | Public transport authority for bus operators. |

## Places

| Term | Meaning |
| --- | --- |
| **IPD** | Ibu Pejabat Polis Daerah. IPD Dang Wangi is the main police station. |
| **Kem Wardieburn** | Military camp. |
| **KLBT** | Kuala Lumpur Bus Terminal / Bandar Bus Terminal. |
| **Hazbank** | Robbable bank target. |
| **CR** | Community Retail. |

## Law and roleplay

| Term | Meaning |
| --- | --- |
| **LTAA** | Leave To Avoid Arrest. Leaving while detained or being arrested can auto-jail you when you return. |
| **RTAA** | Reset To Avoid Arrest. Reset is disabled at low health to prevent this. |
| **Saman** | Summons or fine, usually issued by police. |
| **BOLO** | Be On the LookOut. A police alert for a suspect. |
| **MDT** | Mobile Data Terminal, the police tablet app. |
| **Ammulaysia** | Licensed gun dealer. Requires the Firearms Licence gamepass. |
